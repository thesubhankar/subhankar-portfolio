# Portfolio Common Rules — React + Tailwind + GSAP + Lenis

Build a premium personal portfolio for Subhankar Giri, Data Scientist & Data Analyst.

TECH STACK
- React + Vite
- Tailwind CSS
- GSAP + ScrollTrigger
- Lenis
- React Icons

GLOBAL VISUAL STYLE
- Preserve the existing dark notebook/IDE-inspired identity.
- Deep navy/black background with purple depth.
- Neon pink as primary accent and cyan as secondary accent.
- Monospace/code-inspired typography for labels and navigation.
- Thin glowing borders, subtle glass effects, clean spacing.
- Do not overuse gradients or glow.
- Keep the design professional, not game-like.

GLOBAL ANIMATION RULES
- Use GSAP for entrance/reveal animations.
- Use ScrollTrigger for section-based animations.
- Use Lenis for smooth scrolling.
- Prefer transform and opacity animations for performance.
- Animations should feel smooth and premium, not excessive.
- Respect prefers-reduced-motion.
- On mobile, reduce animation distance and duration.

RESPONSIVE RULES
- Desktop: fixed/visible sidebar and spacious layout.
- Mobile: hide desktop sidebar and use a hamburger/full-screen or slide-in menu.
- No horizontal overflow.
- Cards, typography and spacing must adapt to mobile.
- Hover-only effects must have touch-friendly alternatives.

CODE RULES
- Each section lives in its own JSX file.
- Keep section-specific content and animation close to that section.
- Reuse common components only when genuinely useful.
- Do not create unnecessary files.
- Use semantic HTML and accessible labels.
- Never invent personal information, statistics, certificates or experience.
